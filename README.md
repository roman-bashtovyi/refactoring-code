# refactoring-code

A Claude Code skill for readable code: guard clauses, loops instead of dense `array_*` / `.map().filter()` chains, no nested ternaries, honest names. Includes all smells and techniques of [refactoring.guru](https://refactoring.guru/refactoring) in short form, with PHP/TS and React examples.

## Install

```bash
git clone https://github.com/roman-bashtovyi/refactoring-code.git ~/.claude/skills/refactoring-code
```

## Use

Ask Claude to review, clean up or refactor code — the skill loads by itself. Or call `/refactoring-code`.

Based on Martin Fowler's *Refactoring* and [refactoring.guru](https://refactoring.guru); entries are summaries with links to the pages. MIT license.
